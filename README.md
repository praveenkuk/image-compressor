# CompressPixel

Free static image compressor built for GitHub Pages.

## What it does

- Compresses JPG, PNG, and WebP images in the browser
- Supports batch image processing
- Offers quality, resize, format, and social preset controls
- Shows savings, preview, and a simple image performance score
- Includes starter SEO landing pages, `sitemap.xml`, and `robots.txt`
- Includes About, Contact, Privacy Policy, Cookie Policy, Terms, and Disclaimer pages for ad-review readiness
- Includes visible ad placeholders that can be replaced with AdSense or other ad network code
- Includes a blog section with 20 search-focused image compression articles

## Launch on GitHub Pages

1. Create a GitHub repository named `image-compressor`.
2. Upload these files to the repository.
3. In GitHub, open Settings > Pages.
4. Select the main branch and root folder.
5. Your site will be available at `https://praveenkuk.github.io/image-compressor/`.

## Repository license setting

Use `No license` when creating the GitHub repository. The site includes a visible all-rights-reserved copyright notice, and no open-source license file should be added unless you later decide to let others reuse the code.

## Custom domain

A custom domain is optional. Start on GitHub Pages first, then add a domain when a page starts getting impressions or backlinks.

## Before applying for ads

- Keep `praveenkuk` as-is if you are publishing from your GitHub account. Change it only if you use a different GitHub username or a custom domain.
- Replace `hello@example.com`, business name, and location on the contact/legal pages.
- Add real, useful content to SEO pages over time so the site is not only a thin tool page.
- Add Google Analytics, Search Console, and AdSense snippets only after the public URL is live.
